# Media Station X test

The repository includes `msx-test.m3u`, a test playlist for comparing playback in Media Station X and SS IPTV.

## Setup
1. Open the official Media Station X M3U Launcher: https://msx.benzac.de/info/m3u.html
2. Enter the public raw URL of `msx-test.m3u` from this repository.
3. Follow the launcher's instructions to create a start parameter / start URL.
4. In Media Station X on the TV, open Settings → Start Parameter → Setup and enter the value produced by the launcher.
5. Compare the same channel in both players on the same Wi-Fi connection.

## Notes
- The playlist labels and stream availability have not been independently verified.
- Use only streams you are authorized to access.
- A playlist cannot reduce stream quality by itself; an SD version must be provided by the source.
- The M3U Launcher requires Media Station X 0.1.145 or newer.
