# PlayTube за Media Station X

Статичен портал с един бутон към началната страница на PlayTube.TV. Той не извлича, препредава или хоства видео потоци.

## Настройка на телевизора

1. Отвори Media Station X.
2. Избери **Settings → Start Parameter → Setup**.
3. Като адрес на сървър въведи:
   `ivanovlyubomir03-max.github.io/iptv-token-manager`
4. Включи HTTPS/защитената настройка, ако приложението я поиска.
5. Потвърди настройката. След това избери **Отвори PlayTube.TV** и после **Отвори сайта**.

Ако телевизорът или неговата версия на Media Station X не приема адрес с път `/iptv-token-manager`, този GitHub Pages адрес може да не се конфигурира като Start Parameter. В такъв случай може да се ползва директната страница:
https://ivanovlyubomir03-max.github.io/iptv-token-manager/

Дори когато порталът се отвори, телевизорът може да не поддържа уебплеъра или кодека на външния сайт.
