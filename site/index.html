PlayTube за Media Station X

Този портал добавя бутон в Media Station X, който отваря началната страница на PlayTube.TV.

В Media Station X: Settings → Start Parameter → Setup. Въведи адреса на GitHub Pages сайта и включи защитената HTTPS настройка, ако бъде поискана.

Отвори портала в Media Station X Порталът само отваря PlayTube.TV. Не копира и не хоства видеа. Работата на сайта зависи от поддръжката на уеб съдържание в телевизора и от самия PlayTube.
